# МДК 01.04 Системное программирование

Специальность: 09.02.07 «Информационные системы и программирование» (ИП)

Курс посвящён системному программированию на платформе .NET: от основ языка C# и объектно-ориентированного программирования — к многопоточности и асинхронности, обработке файлов (Word, Excel, PDF), работе с базами данных (Entity Framework Core + PostgreSQL 16), разработке веб-приложений на ASP.NET Core, фоновым задачам (Hangfire), валидации (FluentValidation) и логированию (Serilog).

## Требования к окружению

- **.NET SDK 10** (LTS) — установка: `winget install Microsoft.DotNet.SDK.10`
- **VS Code** с расширением **C# Dev Kit** — среда разработки (работа через `dotnet` CLI)
- **Git** — система контроля версий
- **PostgreSQL 16** — сервер базы данных (Раздел 5)
- **pgAdmin** — графический клиент для PostgreSQL (входит в установщик PostgreSQL)
- Docker не используется: все задания выполняются локально с установленными .NET SDK и PostgreSQL
