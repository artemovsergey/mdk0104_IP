# Практическая работа

Как профессиональный .NET разработчик создай практическую работу для студентов на тему: Создание классов и объектов. В практической работе должно быть: тема, цель, ход работы, теоретическая часть, практический пример, 15 вариантов простых заданий, критерии оценки от 2 до 5, контрольные вопросы. Вариант выбирается по номеру в журнале. В репозитории должны быть: проект решения, папка images со скриншотами работы программы, readme.md. В файле readme.md: номер, название практической работы, вариант и текст задания, оформление кода подсветкой синтаксиса, скриншоты результата. Готовая практическая работа должна быть выложена на локальный git сервер gogs
